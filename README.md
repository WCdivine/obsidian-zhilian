# 织链 · Obsidian 观点级双链工作流

**一句话**：一条 slash 命令，让你的编码 agent（ZCode / Claude Code）对 Obsidian 笔记做**观点级**织链——提取主张、判定类型化的边、经你确认后写入库。单位是"主张"而非笔记，只看标题建链接在这个工作流里不算织链。

> **TL;DR (EN)**: A slash-command workflow that upgrades Obsidian backlinks from *note-level* to *claim-level*. Your agent extracts the claims inside a note, scans the vault for collisions, classifies each relation into one of seven typed edges (with quoted evidence and a justification, or no edge at all), proposes the changes, and only writes after your confirmation.

## 为什么不是又一个"自动打链接"工具

AI+PKM 工具的主流做法是语义相似度推荐：算向量、找相似、塞链接。织链反着来：

| 常见做法 | 织链的纪律 |
|---|---|
| 笔记 A 和 B 相似 → 建链 | 提取 A 里的**主张**，去撞 B 里的主张；标题命中不算数 |
| 边没有类型，"相关"万岁 | 七种类型，**无类型不建**；每条边必须附双方原文引用 + 一两句论证，**论证不出来就不建** |
| 相似 = 有价值 | 最有价值的恰恰是**对撞**：反对、限定、张力、跨域同构 |
| 自动写入，链接越堆越多 | 默认只出建议清单，**未经确认绝不写盘** |
| 链接网越密越好 | 论域页不冒充 MOC：不按学科收成员，只收实际发生纠缠的观点 |

## 七种边

| 类型 | 含义 |
|---|---|
| 支持 | 一条主张为另一条提供理由或证据 |
| 反对 | 两者不能同时成立 |
| **限定** | A 在何条件下成立而 B 超出了这个条件 |
| 前提 | A 成立依赖 B 成立 |
| **跨域同构** | 不同域的同一结构（如 数学 ↔ 认识论）——最值钱的一类 |
| 例证 | 用具体案例撑起抽象主张 |
| **张力** | 两边都成立但未调和——挂起不裁决，挂着养 |

"张力"是这个工作流特有的发明：矛盾不必当场解决，在论域页的挂起区放着，等理论长到能调和它的那天。

## 工作流（六步）

1. **定位**：按参数找笔记，或取最近激活的 .md；
2. **提主张**：完整读入，产出 C1..Cn（断言/区分/例证/方法），标注裂缝与"在建"；
3. **扫库对撞**：用主张的关键词（不是标题词）rg 全库，候选**读全文**再提对方主张；
4. **判边**：七类之一 + 原文引用 + 论证，否则不建；
5. **出建议清单**：行内链接（落在主张那句的句尾）+ 需要时新建论域页；用户回复「应用」/「应用 N」/调整；
6. **写入**：确认后逐条 Edit，最小改动，保持原文风格。

论域页（代替 MOC）的结构：`frontmatter(类型: 论域, 状态)` → 双侧主张清单 → 类型化边 → 挂起区 → `← 返回 [[导航]]`。完整样例见 [`examples/论域页样例-红皇后效应与内卷.md`](examples/论域页样例-红皇后效应与内卷.md)，配套的笔记侧样例见 [`examples/笔记样例-演化稳定与竞争.md`](examples/笔记样例-演化稳定与竞争.md)。

## 安装

**ZCode**：把 [`织链.md`](织链.md) 放进 `~/.zcode/commands/`。

**Claude Code**：同格式兼容，放进 `~/.claude/commands/`。

然后打开 `织链.md`，把顶部的 `{{VAULT_PATH}}` 改成你的库根目录，`概念/` 改成你的论域页目录（没有就保持默认，它会新建）。

依赖：`rg`（ripgrep）在 PATH 中。

## 使用

```
/织链              # 对最近激活的笔记织链
/织链 某篇笔记      # 按文件名模糊匹配
```

织完先出建议清单，回复「应用」才落盘。

## 设计取舍

- **为什么确认制**：库是你的第二大脑，agent 不该有写权限的默认信任。所有写入逐条报告，可单独撤销。
- **为什么论域页而不是 MOC**：MOC 按主题收笔记，论域页只收**实际发生纠缠的观点**。前者是目录，后者是战场。
- **为什么边要引用原文**：防止 agent 用自己的话复述主张时偷偷换掉了论点——引用让偷换无处遁形。
- **裂缝标注**：笔记内部的自相矛盾单独标出（`C-k 裂缝`），裂缝常是与外部观点对撞的同构点。

## 适用与不适用

适用：观点密集的个人库（读书笔记、理论笔记、研究札记）。
不适用：模板化收集箱、纯剪藏库——没有主张的笔记无链可织，这是特性不是缺陷。
